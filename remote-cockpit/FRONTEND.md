# FRONTEND.md

## Vision

The Android application should feel like:

"Mission Control for Development."

Not:

"Tiny Desktop."

---

## Primary Navigation

Bottom Tabs

1. Terminal
2. Files
3. Dashboard
4. AI
5. Settings

---

## Terminal Screen

Functions:

* Live terminal output
* Command input
* Command history
* Session reconnect

Priority:

Highest

This is the most important feature.

---

## Files Screen

Functions:

* Browse folders
* Open source files
* Preview images
* Preview markdown

Read-only for Version 1.

---

## Dashboard Screen

Cards:

* CPU
* RAM
* GPU
* Disk

Additional Cards:

* ROS2 Status
* Isaac Lab Status

---

## AI Screen

Examples:

"Find MPC weight definition"

"Summarize today's work"

"Why did training stop"

"Show modified planner files"

---

## Notifications

Push notifications:

* Build completed
* Training completed
* Training failed
* System offline

---

## User Experience Principles

Rule 1

One-handed operation.

Rule 2

Fast loading.

Rule 3

Readable outdoors.

Rule 4

Never require desktop zooming.

Rule 5

Most information accessible within three taps.
